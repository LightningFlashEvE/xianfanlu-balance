# 飞升继承系统设计文档

## 系统总览

**一个逻辑，三种出路**：飞升前，玩家选定最多三件"命器"；飞升后，它们被封印，需完成专属任务才能苏醒为可成长的"红尘仙兵"。未被选的装备，则通过分解、转生等方式在仙界发挥余热。

| 继承路线 | 适用装备 | 仙界结果 | 核心玩法 |
|---------|---------|---------|---------|
| ① 本命共炼 | 精心培养、有感情的凡界装备（最多 3 件） | 可成长仙器（红尘仙兵） | 专属觉醒任务链，独立成长技能树 |
| ② 本源继承 | 一切有特性的凡界装备 | 稀有消耗品（器魂精魄） | 分解凡器，为仙界新装备附加一条凡界绝技 |
| ③ 灵识转生 | 生出灵性的凡界装备 | 独立器灵（可嵌入新装备） | 器灵养成，为仙界装备提供专属被动技能 |

### 互斥关系

```
飞升时拥有约 12~14 件装备

├── ≤ 3 件 → 本命共炼（红尘仙兵）
├── N 件 → 本源继承（器魂精魄）
└── M 件 → 灵识转生（器灵）

规则：
- 本命共炼的装备不能再走 ② 或 ③
- 本源继承和灵识转生互斥（分解了就没有器灵了）
- 实际选择：3 件命器 + (N 件精魄 XOR M 件器灵)
```

## 路线①：本命共炼 → 红尘仙兵

### 选人条件

```
飞升前选定 ≤ 3 件装备作为"命器"
条件：品质 ≥ 良品 且 balanceRealm ≤ 飞升时境界
（凡品不行——凡铁就是凡铁，没有灵性可炼）
```

### 飞升后状态：封印

飞升瞬间，命器被仙界法则压制，进入「封印态」：

```
封印态属性 = 凡界属性 × 0.15（几乎废铁）
```

设计意图：如果继承系数太高，红尘仙兵直接碾压仙界装备，那仙界就没有探索的意义了。0.15 让玩家感受到"失去"，为觉醒任务提供情感驱动力。

### 觉醒任务链（3 阶解封）

每完成一阶，解封一部分属性 + 解锁一个技能树节点：

| 阶段 | 任务核心 | 继承系数 | 解锁内容 |
|------|---------|---------|---------|
| 初醒 | 用封印态武器击杀 3 个仙界敌人 | 0.15 → 0.35 | 基础属性恢复 + 初醒技能 |
| 共鸣 | 收集 1 件仙界材料与命器融合 | 0.35 → 0.60 | 属性大幅增长 + 共鸣技能 |
| 归一 | 在仙界秘境中完成专属试炼 | 0.60 → 0.85 | 属性接近仙界装备 + 终极技能 |

### 红尘仙兵技能树

每种装备类型有固定的 3 个技能，按阶段解锁：

```
┌─────────────────────────────────┐
│      玄铁矛 · 红尘仙兵           │
├─────────────────────────────────┤
│                                 │
│  ┌──────┐   ┌──────┐           │
│  │ 初醒 │──→│ 共鸣 │──→ 归一   │
│  └──┬───┘   └──┬───┘     │     │
│     │          │         │     │
│  破甲之忆    矛意贯通    红尘不灭 │
│  (被动)      (主动)     (终极)  │
│  无视 12%    蓄力一击    濒死时  │
│  敌方防御    伤害 ×2.5   全属性  │
│             冷却 8 回合  +25%    │
│                        持续 3 回合│
└─────────────────────────────────┘
```

技能设计原则：
- **初醒技能**（被动）：和凡界使用记忆相关
- **共鸣技能**（主动）：融合仙界材料后的新能力
- **归一技能**（终极）：凡界与仙界融合的终极形态

技能效果不叠加在属性上，而是提供独特的战斗机制。红尘仙兵和仙界装备的差异不是"谁数字大"，而是"谁打法更有趣"。

### 数值示例

以「玄铁矛」（筑基期武器）为例：

```
凡界玄铁矛：attackFlat=38, attackPercent=0.15

飞升后（封印态 ×0.15）：attackFlat=6, attackPercent=0.02
初醒后（×0.35）：attackFlat=13, attackPercent=0.05
共鸣后（×0.60）：attackFlat=23, attackPercent=0.09
归一后（×0.85）：attackFlat=32, attackPercent=0.13

仙界原生矛（元婴期）：attackFlat≈65, attackPercent≈0.16
仙界原生矛（化神期）：attackFlat≈120, attackPercent≈0.22
```

红尘仙兵的数值永远追不上仙界高阶原生装备，但其独特技能树提供不可替代的战术价值。

### 平衡约束

| 约束 | 规则 | 原因 |
|------|------|------|
| 上限 3 件 | 飞升前只能选 3 件 | 选择有意义 |
| 不可交易 | 绑定角色 | 红尘仙兵是个人故事 |
| 归一后锁定 | 继承系数不再增长 | 防止无限成长 |
| 技能树固定 | 每件装备 3 个技能，不可重置 | 选择有代价 |

## 路线②：本源继承 → 器魂精魄

### 适用条件

```
任何有 combat 属性的凡界装备
（纯储物袋、纯机缘物不行——没有战斗记忆可提取）
```

### 分解公式

```
器魂精魄效果 = 凡界装备属性 × 继承系数

继承系数 = 基础 0.12 + 品质加成
  凡品：0.12
  良品：0.15
  珍品：0.18
  绝品：0.22
```

### 数值示例

| 凡界装备 | 品质 | 属性 | 精魄效果 |
|---------|------|------|---------|
| 旧铁剑 E001 | 凡品 | attackFlat=5 | attackFlat +1 |
| 百炼长刀 E020 | 良品 | attackFlat=14 | attackFlat +2 |
| 青锋法剑 E050 | 珍品 | attackFlat=24 | attackFlat +4 |
| 金丹赤霄剑 E037 | 珍品 | attackFlat=37 | attackFlat +7 |
| 金罡法袍 E036 | 绝品 | hpPercent=0.18 | hpPercent +0.04 |

### 器魂精魄的使用方式

```
仙界装备有「魂槽」：
  白板仙器：0 魂槽
  良品仙器：1 魂槽
  珍品仙器：2 魂槽
  绝品仙器：3 魂槽

每个魂槽可嵌入 1 枚器魂精魄，效果叠加
```

### 平衡约束

| 约束 | 规则 | 原因 |
|------|------|------|
| 不可逆 | 分解后装备消失 | 选择有代价 |
| 同属性上限 | 同一仙器最多 2 个同类精魄 | 防止全堆攻击 |
| 不可提取 | 嵌入后无法取出 | 决策要慎重 |
| 命器互斥 | 已选命器的不能分解 | 取舍 |

## 路线③：灵识转生 → 器灵

### 生出灵性的条件

满足至少一条：

```
条件 A：该装备被使用超过 30 场战斗（陪伴足够久）
条件 B：该装备被炼化过 ≥ 2 次（投入了足够资源）
条件 C：该装备品质 = 绝品（天生灵性）
```

### 器灵被动技能表（固定）

每种装备类型有固定的被动技能方向：

| 装备类型 | 器灵技能名 | 效果 |
|---------|-----------|------|
| 剑 | 剑灵·锐 | 暴击率 +2 |
| 刀 | 刀灵·猛 | 攻击 +3% |
| 枪/矛 | 枪灵·穿 / 矛灵·破 | 攻击 +5 |
| 棍 | 棍灵·稳 | 防御 +4 |
| 拳套 | 拳灵·疾 | 暴击伤害 +15 |
| 暗器 | 暗灵·隐 | 命中率 +3 |
| 弓箭 | 弓灵·远 | 速度 +3 |
| 衣甲 | 甲灵·坚 | 防御 +4% |
| 靴子 | 靴灵·捷 | 闪避 +2 |
| 帽子 | 冠灵·慧 | 灵盾 +8 |
| 护符 | 符灵·护 | 灵盾 +5% |
| 法宝 | 宝灵·威 | 法术威力 +5% |
| 阵盘 | 阵灵·玄 | 法术 +6 |
| 飞剑法器 | 剑灵·御 | 命中 +3 |
| 玉佩 | 玉灵·润 | 生命 +2% |
| 戒指 | 戒灵·锐 | 攻击 +3 |
| 攻击符 | 符灵·爆 | 法术 +5 |
| 防御符 | 符灵·壁 | 防御 +5 |
| 辅助符 | 符灵·辅 | 内力 +5 |
| 战斗傀儡 | 傀灵·忠 | 攻击 +4 |
| 储物袋 | 袋灵·容 | 生命 +10 |
| 机缘物 | 缘灵·运 | 生命 +3% |

### 使用历史影响技能强度

```
战斗次数    技能强度倍率
30~50 场   → 1.0x（基础效果）
50~100 场  → 1.3x（强化效果）
100+ 场    → 1.6x（觉醒效果）
```

示例：
- 旧铁剑的器灵「铁心」：45 场战斗 → 暴击率 +2（基础）
- 百炼长刀的器灵「百斩」：120 场战斗 → 攻击 +6（觉醒：4 × 1.6 = 6.4 → 6）

### 器灵的嵌入

```
仙界装备有「灵位」：
  普通仙器：0 灵位
  有灵性的仙器：1 灵位
  上古仙器：2 灵位

每个灵位可嵌入 1 个器灵，被动技能生效
```

### 器灵的契合度

```
契合度 = 基础 0.6 + 类型匹配加成

同类型（剑灵 → 剑类仙器）：+0.4（共 100%）
同大类（剑灵 → 刀类仙器）：+0.2（共 80%）
不匹配（剑灵 → 甲类仙器）：+0.0（共 60%）

最终效果 = 器灵被动 × 契合度
```

### 平衡约束

| 约束 | 规则 | 原因 |
|------|------|------|
| 器灵不叠加数值 | 只提供被动技能 | 防止数值膨胀 |
| 灵位稀缺 | 大多数仙器只有 0~1 灵位 | 器灵选择有代价 |
| 不可复制 | 每件装备最多生成 1 个器灵 | 唯一性 |
| 器灵可转移 | 取出后可嵌入另一件仙器 | 给玩家调整空间 |

## 数据模型

### 装备 schema 扩展

在 `equipment.library.json` 中，每件装备新增 `ascension` 字段：

```json
{
  "id": "E031",
  "name": "玄铁矛",
  "quality": "珍品",
  "ascension": {
    "canRefine": true,
    "maxRefineTier": 3,
    "spiritName": "玄铁",
    "spiritSkillHint": "玄铁沉重如山的战意，每一刺都带着千钧之力"
  }
}
```

| 字段 | 说明 |
|------|------|
| `canRefine` | 是否可炼化（凡品 false，良品以上 true） |
| `maxRefineTier` | 最高炼化等级（0=不可，2=灵品，3=宝品，4=仙品） |
| `spiritName` | 器灵名字（预设，不填则自动生成） |
| `spiritSkillHint` | 器灵技能提示（描述器灵的故事感） |

### 飞升继承清单

```typescript
type AscensionPlan = {
  lifeBoundIds: string[];       // ≤3 件命器
  essenceDecomposeIds: string[]; // 分解为精魄
  spiritRebirthIds: string[];   // 转生为器灵
};
```

### 核心函数

| 函数 | 说明 |
|------|------|
| `canBeLifeBound(equip)` | 品质 ≥ 良品 |
| `canDecomposeToEssence(equip)` | 有 combat 属性 |
| `canSpawnSpirit(equip, battleCount)` | 绝品 / 战斗 ≥30 场 / 炼化 ≥2 次 |
| `validateAscensionPlan(plan, equipment)` | 验证清单合法性 |
| `executeAscension(plan, equipment, battleCounts)` | 执行飞升，生成所有继承物 |
| `createImmortalWeapon(equip, stage)` | 生成红尘仙兵 |
| `advanceImmortalWeapon(weapon)` | 红尘仙兵进阶 |
| `createArtifactSoulEssence(equip)` | 生成器魂精魄 |
| `createArtifactSpirit(equip, battleCount)` | 生成器灵 |
| `calculateSpiritAffinity(spirit, target)` | 计算器灵契合度 |
